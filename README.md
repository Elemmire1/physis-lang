# Physis-Lang

Static research website for Physis-Lang, with the updated release paper and all demo media included.

## Publish with GitHub Pages

1. Create a public repository named `physis-lang` under `Elemmire1`.
2. Upload the contents of this folder to the repository root. `index.html`, `assets/`, and `demo/` must be at the root, not inside another `physis-lang` or `dist` folder. Include `.nojekyll` when possible.
3. In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and click **Save**.
4. Wait for the Pages deployment to finish. The expected address is https://elemmire1.github.io/physis-lang/.

No build command, Node.js installation, or parent project directory is required. All essential media and the paper are local; Google Fonts are optional.

## Editing

- `index.html`: page content
- `style.css`: layout and appearance
- `site.js`: animated charts and player controls
- `assets/Physis-Lang.pdf`: paper, replaced from the user-supplied `Physis-Lang_arxiv.pdf`
- `demo/`: interactive overview and its media

The website is independent of the Chinese article's Markdown and Word documents.
